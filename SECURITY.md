# Security

Do not publish tokens, passwords, private URLs, database backups, or activity
exports in an issue. Report a vulnerability through GitHub private vulnerability
reporting when available, or contact the maintainer through https://kylbutlr.com.

Only the latest public release receives fixes. Passwordless access is an explicit
loopback-only mode. Hosted access must retain server-side authentication. Do not
use an unrestricted local mode as a public hosting configuration.
