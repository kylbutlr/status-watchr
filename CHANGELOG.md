# Changelog

## macOS 1.0.1

- Fix a startup crash caused by opening the app's own bundle identifier as a named preferences suite. The installed app now uses its standard domain, preserving existing settings.
- Verify preferences under the packaged app identity and smoke-test the signed bundle before publication.

## 1.1.0

- Refresh workspace layout, form controls, spacing, and mobile presentation.
- Add browser-local workspace/display names, appearance, density, and default view preferences.
- Use the shared App Stylr native-control recipe with progressive picker styling.


## 1.0.0

- Public self-hosted distribution with setup and privacy documentation.
- Explicit optional password protection for local loopback access.
- App Stylr foundation with bundled fonts and fictional demonstration data.
- Versioned GitHub source/download packages and SHA-256 checksums.

See the release notes for verification evidence and platform limits.
