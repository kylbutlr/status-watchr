# Contributing

Open a focused issue or pull request against https://github.com/kylbutlr/status-watchr.
Use fictional examples and disposable local data. Never include a real workspace,
credentials, or private activity logs. Preserve App Stylr semantic roles and the
application's documented ownership and authorization boundaries.

Follow the README development steps. Include the checks you ran and distinguish
source/automated checks from installed-app or physical-device verification.
